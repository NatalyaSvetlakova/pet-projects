Создание слайд-шоу

В этом проекте мы создадим простое слайд-шоу с изображениями. 
Это слайд-шоу будет циклически воспроизводить заранее заданную коллекцию изображений с заданной скоростью. 
Вы сможете запускать и останавливать его как с помощью мыши, так и с помощью клавиатуры.
В папке с изображениями есть папка slides, а в ней — коллекция файлов с изображениями, 
готовых для использования в слайд-шоу.
Слайд-шоу работает за счёт периодической смены свойства src основного изображения.

В этом проекте мы будем разрабатывать методы

•определения местоположения элементов
•работы с массивами
•разделения строк для создания массива
•предварительной загрузки изображений
•арифметических операций по модулю
•Изменение свойств HTML-элемента
•Реагирование на события пользователя
•Использование функций таймера


Позже вы увидите, как использовать CSS для определенных анимационных эффектов. 
CSS — это язык программирования, который определяет внешний вид HTML-элементов, 
а с помощью JavaScript можно создавать и применять дополнительный CSS.
Если вы знакомы с CSS, это будет полезно, но необязательно. Вам просто понадобится немного веры в себя. 
Просто имейте в виду, что современный CSS можно использовать для всевозможных анимационных трюков, 
которые раньше требовали дополнительного JavaScript. Это позволит вам сосредоточиться на реализации 
логики вашего проекта, а CSS возьмёт на себя визуальные аспекты.

Структура слайд-шоу

Элемент HTML img определяет отображаемое изображение. Как правило, он имеет следующую форму:

	<img src="..." alt="...">

Атрибут src — это URL-адрес реального изображения. 
HTML-код не содержит изображение, но указывает браузеру, 
откуда его взять. Обычно изображение находится на сайте, но оно может быть и удалённым, 
если URL-адрес содержит протоколы http:// или https://.
Когда браузер обнаруживает тег img, он отправляет запрос на изображение, 
указанное в атрибуте src. Как правило, получение изображения занимает некоторое время, 
поэтому браузер продолжает обрабатывать остальную часть HTML-кода. 
Когда с сервера поступает изображение, браузер отображает его в отведенном для него месте.
Если изображение невозможно просмотреть – например, если отсутствует оригинал, 
или требуется слишком много времени, чтобы оно появилось, или если у пользователя проблемы 
со зрением и он полагается на текст, – браузер будет использовать альтернативный текст.

Есть ещё три распространённых атрибута:
 
	<img src="..." alt="..." title="..." width="..." height="...">
	
 Заголовок — это дополнительный текст, который может отображаться при наведении 
 курсора мыши на изображение. 
 Он также помогает поисковым системам описывать изображение. 
 
 Атрибуты width и height помогают браузеру 
 создать подходящее пространство для изображения, пока оно загружается.  
 Их также можно использовать для изменения размера изображения.
 
Наше слайд-шоу будет циклически перебирать коллекцию изображений, 
изменяя значение атрибута src, что приведёт к перезагрузке нового изображения в браузере.
Всё слайд-шоу будет заключено в следующую структуру:

	<div id="slides">
		<img width="640" height="480" src="" title="..." alt="...">
	</div>
	
Элемент div — это универсальный блочный контейнер. Он часто используется для вёрстки. 
С помощью CSS элемент div преобразуется в контейнер для изображения.

Подготовка HTML

Для работы скрипта необходимо две ссылки на JavaScript:
	<head>
		<title>Слайд-шоу</title>
		...
		<script type="text/javascript" src="scripts/library.js"
			crossorigin="anonymous">
		</script>
		<script type="text/javascript" src="scripts/slideshow.js" crossorigin="anonymous" defer>
		
		</script>
	</head>

Как и в случае с другими проектами, файл slideshow.js 
будет содержать основной код. Однако сам код для запуска слайд-шоу может 
пригодиться вам в других проектах; он точно понадобится вам для варианта слайд-шоу, 
который будет описан далее в книге. По этой причине этот код будет помещён в файл library.js 
для повторного использования.
 Также обратите внимание, что библиотеке не нужен атрибут defer, 
 так как она не будет мешать загрузке страницы или зависеть от неё.
Для этого проекта вам понадобится какой-нибудь веб-сервер, как описано во введении. 
Если вы загружаете файлы напрямую в веб-браузер, удалите часть crossorigin="anonymous".

Массив изображений


Когда мы говорим о коллекции, мы часто имеем в виду массив — пронумерованную коллекцию. Пример массива:
 var fruit = ['apple', 'banana', 'cherry', 'date'];
Номер каждого элемента называется его индексом. В JavaScript индекс начинается с 0, 
поэтому индексы, показанные ранее, — это 0, 1, 2 и 3.
Вам нужно знать, сколько элементов в массиве. В JavaScript это свойство length массива: 
console.log(fruit.length);//4
Обратите внимание, что, поскольку индекс начинается с 0, длина на единицу больше последнего индекса.

Если вам не хочется вводить его, вот фрагмент для этого массива.

Строка div#slides совпадает с селектором CSS и означает «элемент div с идентификатором slides».

Загрузка изображения

В настоящее время элемент img пуст, так как у него нет допустимого значения src. Мы изменим это в нашем коде.
Сначала вам нужно получить элемент-контейнер, а также внутренний элемент img:

	// library.js
	function doSlides(images, containerSelector) {
		// Элементы
		let container = document.querySelector(containerSelector);
		let img = container.querySelector('img');
	};

Переменная container будет ссылаться на содержащий её элемент div, 
что важно для некоторых более сложных частей слайд-шоу. 
Переменная img будет ссылаться на сам элемент img, атрибут src которого мы будем задавать.

Обычно элемент находят с помощью document.querySelector(), 
как мы сделали с элементом container. При этом выполняется поиск 
первого совпадения во всём документе. Однако можно ограничить поиск 
определённым элементом, как мы сделали с элементом img: container.querySelector() будет выполнять поиск только внутри элемента container. Это не только немного ускоряет процесс, поскольку JavaScript не нужно искать не там, где нужно, но и позволяет игнорировать другие элементы img, которые нас не интересуют.
Чтобы загрузить изображение, нужно задать атрибут src для элемента img. 
Мы можем попробовать сделать это с одним конкретным изображением:

	function doSlides(images, containerSelector) {
		// Элементы
		let container = document.querySelector(containerSelector);
		let img = container.querySelector('img');
		img.src = 'images/slides/bamboo.jpg';
	};

Поскольку в массиве изображений указаны только имена файлов, мы добавили путь 
к этим изображениям относительно корня сайта. Это делает код более гибким, 
поскольку мы можем легко изменить расположение изображений, не меняя саму коллекцию.
 Если вы перезагрузите страницу, то увидите изображение.
 Поскольку у нас есть целая коллекция изображений, мы должны использовать одно из них из массива:
 
	function doSlides(images, containerSelector) {
		// Элементы
		let container = document.querySelector(selectorOfContainer);
		let img = container.querySelector('img');
		img.src = `images/slides/${images[0]}`; // ← обратные кавычки
	};
	
Обратите внимание на другие кавычки (` ... `), так называемые обратные кавычки. 
Этот тип строк называется шаблонным литералом. Для обычного текста эффект такой же, 
как при использовании одинарных или двойных кавычек, но шаблонные литералы позволяют 
встраивать значения и вычисления в синтаксис ${...}.
 Здесь мы жестко задали путь, но подставили фактическое имя файла изображения.
 Если вы перезагрузите страницу, то увидите то же изображение. По крайней мере, вы увидите, 
 что это работает.
 Конечно, вам захочется повторно задавать img.src для каждого нового изображения, 
 поэтому лучше поместить это в функцию:

	function doSlides(images, containerSelector) {
		// Элементы
		let container = document.querySelector(containerSelector);
		let img = container.querySelector('img');
		next();
		function next() {
			// Загрузка изображения
			img.src = `images/slides/${images[0]}`;
		}
	};
	
 Поместив этот код в функцию, вы сможете вызывать его многократно. 
 Вы также можете отложить вызов на некоторое время:
 
	function doSlides(images, containerSelector) {
		...
		setTimeout(next, 3000);
		// next();
		...
	}

Функция setTimeout() принимает ссылку на функцию, которую нужно вызвать (next), 
и количество миллисекунд ожидания (3000). Вы также можете встретить запись windows.setTimeout(). 
Здесь вы ожидаете три секунды, прежде чем вызвать функцию.
Теперь, если вы перезагрузите страницу, изображение появится через три секунды.
Обратите внимание, что ссылка на функцию — next, без скобок. Если вам нужен результат функции, 
используйте скобки (next()). Здесь нам нужен не результат, а сама функция.
 Конечно, функция next() по-прежнему жестко запрограммирована на отображение первого 
 изображения (индекс 0). Чтобы перебрать коллекцию изображений, вам нужно
 
•Задать переменную для индекса
Мы будем использовать переменную slideNumber и зададим ее в новом разделе «Переменные».

•Использовать переменную
Это заменит индекс 0 в массиве изображений.

•Увеличьте значение переменнойЭто можно сделать с помощью оператора инкремента: slideNumber++.

•Повторите вызов функции
Функция setTimeout() вызывает следующую функцию один раз, с задержкой. 

Именно так появляются надоедливые всплывающие окна вскоре после посещения веб-сайта. 
Чтобы вызывать функцию повторно, замените её на setInterval().

	function doSlides(images, containerSelector) {
		// Элементы
		let container = document.querySelector(containerSelector);
		let img = container.querySelector('img');
		// Переменные
		let slideNumber = 0;
		// setTimeout(next, 3000);
		setInterval(next, 3000);
		// next()
		function next() {
			// Загрузка изображения
			img.src = `images/slides/${images[slideNumber]}`;
			slideNumber++;
		}
	}
	
 Выражение slideNumber++ удобнее, чем slideNumber = slideNumber + 1, и ещё удобнее, 
 если объединить его с предыдущим выражением:
 
	function next() {
		// Загрузка изображения
		img.src = `images/slides/${images[slideNumber++]}`;
	}

В этом выражении slideNumber++ называется оператором постфиксного инкремента, 
поскольку переменная увеличивается только после того, как её значение было использовано. 
Оператор префиксного инкремента ++slideNumber увеличил бы переменную до того, как было использовано 
её значение. Существуют также операторы декремента (--).

Если вы запустите эту версию, она будет работать, но со временем вы столкнётесь с новой проблемой. 
(Если «со временем» — это слишком долго, вы можете сократить задержку, например, до 1000, 
чтобы увидеть проблему раньше.)
 Код будет продолжать работать за пределами массива. Значение slideNumber будет увеличиваться, 
 выходя за верхний предел массива, поэтому вы получите undefined. На самом деле вы не увидите undefined, 
 но заметите, что изображение исчезло.
Для этого потребуется сбросить значение slideNumber, когда вы дойдёте до конца:

	function next() {
		// Заполнить изображение
		img.src = `images/slides/${images[slideNumber++]}`;
		// Циклический переход
		if(slideNumber >= images.length) slideNumber = 0;
	};
	
Помните, что длина массива на единицу больше последнего индекса, 
поэтому, когда вы достигнете этого значения (slideNumber == images.length), вы уже зашли слишком далеко. В соответствии с правилами вы всегда должны проверять, не продвинулись ли вы ещё дальше (slideNumber >= images.length), на случай если вы пропустили это раньше. Например, вы уже знаете, что многократное прибавление 0,1 не всегда приводит к простому результату.
 Это сработает, но вы можете легко внести два улучшения. Во-первых, 
 перед отображением первого изображения должна быть задержка, а во-вторых, 
 задержка между слайдами должна быть более настраиваемой.

Отображение первого слайда
 Функция setInterval() ожидает окончания задержки, прежде чем вызвать функцию next(). 
 Вы можете сразу отобразить первый слайд, вызвав функцию next() в начале:
 
	 function doSlides(images, containerSelector) {
		//...
		setInterval(next, 3000);
		next();
		//...
	};
	
Теперь начнётся показ первого слайда, а последующие слайды будут циклически сменяться.

Изменение задержки
Как правило, не следует жестко задавать произвольные значения в середине кода. 
Лучше заранее задать значение в переменной.
В данном случае фактическое значение задержки не является ключевым для логики кода, 
поэтому мы зададим его в качестве параметра функции и позволим вызывающему коду решать,
 каким оно должно быть.
В основном коде укажите задержку в качестве дополнительного аргумента:

	// slideshow.js
	function init() {
		let images = [...];
		doSlides(images, 'div#slides', 3000);
	};
	
 В JavaScript не считается ошибкой добавление дополнительных аргументов в функцию, 
 которые она не ожидает. Это отличает его от большинства других языков программирования. 
 Это значит, что если вы попробуете запустить код без каких-либо изменений, 
 он будет работать: функция doSlides() просто проигнорирует дополнительное значение.
 
Конечно, не стоит игнорировать дополнительную ценность, поэтому в библиотечной 
функции укажите дополнительную переменную-параметр:

	// library.js
	function doSlides(images, containerSelector, delay=3000) {
	...
	}

 Третий параметр имеет значение по умолчанию: если вызывающая функция не 
 указывает третий аргумент, то используется это значение. Это гарантирует, 
 что старое поведение останется неизменным, поскольку изначально третий 
 аргумент не требовался.
	
	________________________________________________________________
	При внесении улучшений в функцию всегда 
	следует стараться сохранить совместимость с предыдущими версиями. 
	Здесь мы добавили значение по умолчанию, чтобы без дополнительного 
	аргумента функция работала так же, как и раньше.

	Очевидно, что в данном случае функция slideShow() всё ещё 
	находится в разработке, поэтому беспокоиться о совместимости не стоит. 
	Тем не менее мы проделали эту работу, чтобы донести свою мысль.
	_________________________________________________________________
	
Наконец, используйте переменную вместо жестко заданного значения в функции setInterval():

 
		function doSlides(images, containerSelector, delay=3000) {
		...
		setInterval(next, delay);
		next();
		...
		}
		
Для тестирования можно ускорить слайд-шоу, используя небольшое значение задержки, 
например doSlides(images, 'div#slides', 1000); или даже меньшее.

Остановка и запуск слайд-шоу

Вероятно, вы уже дошли до того, что слайд-шоу начинает вас раздражать. 
Оно точно будет раздражать пользователей, если вы заставите их смотреть анимацию 
без остановки, как в старых анимированных гифках. Самое меньшее, что вы можете сделать, — 
это дать пользователям возможность приостановить слайд-шоу, что гораздо лучше, 
чем заставлять их переходить на другой сайт.
Хотя вы можете написать код, который будет приостанавливать слайд-шоу, когда пользователь 
наводит курсор на изображение, это не самый естественный подход. Лучше добавить кнопку для паузы. 
Эта же кнопка возобновит показ слайдов. Кнопку, которая переключается между 
двумя состояниями (показ и пауза), часто называют тумблером.
Позже мы добавим настоящую кнопку с помощью JavaScript. А пока мы можем использовать 
само изображение в качестве кнопки.
Чтобы реализовать тумблер, мы выполним следующие действия:

•Создадим переменную для хранения текущего состояния.
•Создайте функцию для приостановки или возобновления слайд-шоу в зависимости от состояния.
•Настройте функцию так, чтобы она реагировала на нажатие на изображение.

Переменная состояния

Для начала мы добавим новую переменную running:

	function doSlides(images, containerSelector, delay=3000) {
		// Элементы
		//...
		// Переменные
		let slideNumber = 0;
		let running; // undefined
		//...
	};
	
 Это слово сбивает с толку, поскольку оно не означает, что переменная 
не определена. Значение undefined — это специальное значение, которое используется 
для обозначения того, что переменная не заполнена. В других языках программирования 
нет такого специального значения, и при попытке использовать переменную до того, 
как ей будет присвоено реальное значение, будут возникать ошибки.
 Чтобы задать переменную состояния, присвойте ей результат функции setInterval():
 
	function doSlides(images, containerSelector, delay=3000) {
		//...
		running = setInterval(next, delay);
		next();
		//...
	};
	
В JavaScript все функции возвращают значение. 
Если нет специального оператора return, функция вернёт значение undefined. 
Вы можете либо использовать это значение, например присвоить его переменной, 
либо полностью проигнорировать возвращаемое значение, как мы делали до сих пор.
 Метод setInterval() в принципе можно использовать со многими функциями. 
 При каждом вызове создаётся так называемый таймер. Возвращаемое значение setInterval() — это intervalID, 
 ссылка на вновь созданный таймер. Это нужно на случай, если вы захотите очистить таймер, 
 чтобы приостановить слайд-шоу.
 Функция setTimeout(), которую мы использовали ранее, 
 работает аналогичным образом, и вы можете использовать возвращаемое 
 значение для отмены отложенного вызова функции.
 
 Функция переключения
 
 
Поскольку предполагается, что мы будем останавливать и запускать показ 
слайдов несколько раз, запускать его сразу один раз уже нецелесообразно. 
Вместо этого мы должны поместить процесс в другую функцию и вызывать ее по 
мере необходимости. В этом случае мы будем называть это функцией toggle():

	function doSlides(images, containerSelector, delay=3000) {
		//...
		// setInterval moved to inside toggle():
		next();
			function toggle() {
				running = setInterval(next, delay);
				next();
			}
			function next() {
			//...
			}
	};

 Нет технической необходимости определять функцию toggle() перед функцией next(); 
 JavaScript обработает все определения функций до фактического запуска кода. 
 На самом деле не имеет значения, решите ли вы определить её после.
 
	________________________________________________________________
	Это не совсем так, если вы пишете код в консоли.  Поскольку 
	консоль 
	не может предугадать, что вы введёте дальше, вам нужно сначала
	определить, на что вы собираетесь ссылаться.
	________________________________________________________________
	
Роль функции toggle() заключается в том, чтобы запустить слайд-шоу, 
если оно ещё не запущено, или остановить его, если оно уже запущено. 
Для этого потребуется конструкция if ... else:

	function toggle() {
		if(!running) {
			running = setInterval(next, delay);
			next();
		}else {
		
		}
	};
	
Помните, что if() проверяет не только на истинное значение, 
но и на «какое-то» значение, например на ненулевое число или непустую строку. 
Специальное значение undefined определённо считается «ничем», поэтому !running проверит, 
является ли оно undefined.
 Чтобы остановить слайд-шоу, используйте функцию clearInterval(), 
 которая принимает в качестве параметра ранее сохранённый идентификатор интервала. 
 Вам также нужно будет сбросить значение running для следующего раза.
 
	function toggle() {
		if(!running) {
		...
		}else {
			clearInterval(running);
			running = undefined;
		}
	}
 Как оказалось, функция clearInterval() возвращает undefined. 
 Мы можем воспользоваться этим, присвоив значение переменной running:
 
	function toggle() {
		if(!running) {
			...
		}
		else {
			running = clearInterval(running);
		}
	};
	
 На этом этапе, если вы протестируете код, то обнаружите, 
 что пока при нажатии на изображение ничего не происходит.
 
 Нажатие на изображение
 
 
Пока что мы сделаем так, чтобы нажатие на изображение приостанавливало 
или возобновляло слайд-шоу, то есть изображение будет выполнять функцию большой кнопки.
Действие пользователя, например щелчок мышью или ввод символа, называется событием. 
Код, который реагирует на событие, называется обработчиком событий. 
Обработчик событий всегда является функцией.
Здесь мы назначим функцию toggle в качестве обработчика событий для элемента img.
Обычно есть два способа настроить обработчик событий. Классический 
способ — напрямую задать одно из свойств для прослушивания событий:

	function doSlides(images, containerSelector, delay=3000) {
		//...
		img.onclick = toggle;
		next();
		//...
	};

Если вы попробуете это сделать, слайд-шоу ещё не начнётся, 
так как оно ждёт, пока вы нажмёте на изображение.

Свойство onclick срабатывает, когда вы нажимаете на элемент 
мышью или касаетесь его на сенсорном экране. Опять же, 
вы используете функцию toggle без скобок, так как обращаетесь к функции,
но не вызываете её (пока).
Не поддавайтесь желанию написать свойство как onClick. 
JavaScript примет такое присвоение, но, поскольку имя чувствительно к регистру, 
оно не будет реагировать на событие click.

То же самое относится к onlick, что является довольно распространённой опечаткой.
Доступно множество свойств для прослушивания событий, например .onmouseover 
для определения наведения курсора мыши на элемент или .onkeyup для определения активности клавиатуры.
 Добавить прослушиватель событий таким способом просто, но у него есть некоторые недостатки:
 
•Таким способом можно добавить только один прослушиватель событий.

•Если элемент находится внутри другого элемента с прослушивателем событий, 
 вы не можете контролировать, какое событие произойдёт первым.
 
•Есть несколько (более новых) типов событий, для которых не предусмотрены 
 простые свойства прослушивателя событий, такие как onclick.
 
 
 Более новый и комплексный метод — использовать функцию addEventListener():
 
	function doSlides(images, containerSelector, delay=3000) {
		//...
		img.addEventListener('click', toggle);
		next();
		//...
	};


В данном случае использование свойства .onclick не имеет особых недостатков, 
и многие разработчики JavaScript предпочтут метод .onclick, но здесь 
мы будем использовать более новый метод на случай, если позже нам 
понадобится его гибкость. Функция addEventListener() также может иметь 
дополнительные параметры для управления своим поведением.

Вот ещё один момент, связанный с типографикой. Фактический тип 
события называется click, и именно его вы вводите в функцию addEventListener(). 
Свойство прослушивателя событий называется .onclick. Опять же, вы не можете 
позволить себе менять написание.
 На этом этапе слайд-шоу загрузит первое изображение благодаря вызову функции next(). 
 Затем оно будет ждать, пока пользователь нажмёт на изображение, чтобы запустить его. 
 Если вы считаете, что оно должно запускаться сразу, вы можете 
 заменить вызов функции next() на toggle():
 
	function doSlides(images, containerSelector, delay=3000) {
		//...
		img.addEventListener('click', toggle);
		// next(); // дождаться, пока пользователь начнёт
		toggle(); // начать сейчас
		//...
	};
	
	
 Здесь вызов функции next() закомментирован, а не удалён. 
 Таким образом, можно легко выбрать одно из двух действий.
 
 Предварительная загрузка изображения
 
 
Скорее всего, вы тестируете все это на своем компьютере, 
поэтому у вас не будет задержек при подключении к Интернету. 
В реальной жизни пользователь сначала столкнется с дополнительной паузой, 
пока браузер загружает следующее изображение. Однако эта пауза исчезнет после первого раза.
Причина такого поведения заключается в следующем:


•Сначала изображение загружается через Интернет, что занимает некоторое время.
•Чтобы избежать дальнейшего ожидания, браузер сохраняет копию изображения в 
 локальном хранилище, которое называется кэшем. В следующий раз, когда 
 понадобится то же изображение, оно будет загружено из кэша, 
 и вы не столкнётесь с такой же задержкой.


  Если вы хотите избежать ожидания загрузки изображения в первый раз, 
  добавить в кэш. Это называется предварительной загрузкой.
Для предварительной выборки изображения мы сначала создадим объект image. 
Этот объект не будет отображаться, а просто будет существовать в памяти. 
При отображении одного изображения мы также будем заполнять этот новый объект 
следующим изображением в массиве. Задержка загрузки изображения будет устранена, 
пока пользователь просматривает текущее изображение.
Чтобы создать новый объект image, мы вызываем специальную функцию Image():

	function doSlides(images, containerSelector, delay=3000) {
		// Elements
		//...
		let prefetch = new Image();
		//...
	};
	
Функция Image() называется функцией-конструктором и 
используется для создания объекта. Объект — это набор данных.
Существует множество встроенных функций-конструкторов, например Date(), 
которая создаёт объект для обработки дат и времени. Вы также можете создавать 
собственные функции-конструкторы для создания пользовательских объектов.
 Функции-конструкторы вызываются с помощью специального ключевого слова new. 
 В принципе, в скобках можно указать дополнительные аргументы для настройки объекта. 
 Если аргументы не требуются, можно вызвать конструктор без скобок: 
 
 let prefetch = new Image;
 
 
 Существуют также функции, которые создают объекты, но 
 не являются конструкторами, например createElement(), о которой мы поговорим позже. 
 У них будет свой способ создания объекта.
 Тем временем объект prefetch будет просто храниться в памяти 
 как виртуальное изображение. Единственное, что нам нужно сделать с ним, — это задать 
 для него свойство src, чтобы браузер загрузил другое изображение. 
 Это происходит внутри функции next():

 
	function next() {
		// Заполнение изображения
		img.src = `images/slides/${images[slideNumber++]}`;
		// Циклический переход
		if(slideNumber>=images.length) slideNumber = 0;
		// Предварительная загрузка
		prefetch.src = `images/slides/${images[slideNumber]}`;
	};
	
 Здесь вы сначала увеличиваете номер слайда (slideNumber++) и 
 используете это новое значение для заполнения prefetch. 
 Если вы копируете и вставляете текст, не увеличивайте slideNumber повторно.
 
 Добавление кнопки к документу
Нажатие на изображение прекрасно подходит для приостановки показа слайдов, но вам может показаться, что на самом деле должна быть соответствующая кнопка. На этом этапе вам придется принять философское решение.
Хороший JavaScript-скрипт должен быть как можно более ненавязчивым и требовать как можно меньше помощи со стороны HTML. HTML предоставляет контейнер для изображений, но от него не требуется ничего дополнительного, например, дополнительных кнопок. Вы также можете подумать о том, может ли HTML предоставлять еще меньше.
Вместо того чтобы определять кнопку в HTML, мы создадим её с помощью JavaScript и вставим в подходящее место. Мы даже установим текст для неё с помощью JavaScript.
 Создание элемента кнопки
Сначала создайте элемент кнопки с помощью document.createElement():
function doSlides(images, containerSelector, delay=3000) {
// Элементы
//...
// Добавить кнопку
let button = document.createElement('button');
// Переменные
//...
};

Функция document.createElement() создаст элемент button, 
но в данный момент он находится только в памяти. Вскоре мы переместим 
его в реальный документ. Прежде чем это сделать, нам нужно 
задать ему несколько важных свойств:

	function doSlides(images, containerSelector, delay=3000) {
		...
		// Add Button
		let button = document.createElement('button');
		button.id = 'run-button';
		button.textContent = 'Start';
		...
	};

Измените его, когда мы приостановим или возобновим слайд-шоу.
 Идентификатор не является обязательным, так как он не понадобится для работы. 
 Однако, если вы хотите как-то повлиять на его внешний вид, вам нужно 
 будет указать его в CSS. В прикреплённом файле CSS есть правила стиля 
 для кнопки #run-button. Конечно, вы можете использовать любой идентификатор, 
 если соответствующим образом измените CSS.
Кнопка нужна для того, чтобы приостанавливать и возобновлять слайд-шоу, 
поэтому мы подключим обработчик событий, как и в случае с изображением:

	function doSlides(images, containerSelector, delay=3000) {
		...
		img.addEventListener('click', toggle);
		button.addEventListener('click', toggle);
		...
	};

Наконец, нам нужно добавить в документ элемент button.	
Кнопку можно разместить в разных местах, но имеет смысл расположить её 
где-то рядом с элементом div, содержащим элемент img. 
Это легко сделать с помощью функции insertAdjacentElement().
 
 
 В нашем случае мы добавим кнопку внутри контейнера в конце:
 
	function doSlides(images, containerSelector, delay=3000) {
		...
		let button = document.createElement('button');
		button.id = 'run-button';
		button.textContent = 'Старт';
		container.insertAdjacentElement('beforeend', button);
		...
	};

Если вы не видите новую кнопку, наведите указатель мыши на 
её едва заметное изображение в правом нижнем углу контейнера. 
CSS отвечает за размещение кнопки поверх изображения, её затемнение 
и выделение при наведении указателя мыши. Соответствующая часть CSS выглядит примерно так:

	button#run-button {
	...
	position: absolute;
	bottom: 1em; right: 1em;
	непрозрачность: 0,2;
	переход: непрозрачность 500 мс;
	}
	button#run-button:hover {
	непрозрачность: 1;
	}
	
 На этом этапе вы можете решить, что вам не нужно, чтобы всё изображение выступало в роли кнопки:
 
	// img.addEventListener('click', toggle);
	
	Оператор закомментирован, а не удалён на случай, если вы всё-таки решите его использовать.
 Проблема в том, что текст на кнопке сбивает с толку.
 
 
 Изменение текста кнопки
 
Изначально в тексте кнопки указано "Начать". Он должен измениться 
на "Остановить" во время показа слайдов и обратно на "Начать" во 
время паузы. Это должно быть сделано с помощью функции toggle().

	function toggle() {
		if(!running) {
			running = setInterval(next, delay);
			next();
			button.textContent = 'Stop';
		}
		else {
			running = clearInterval(running);
			button.textContent = 'Start';
		}
	};

 Теперь кнопка выглядит более осмысленно.
 
 Изменение внешнего вида
 
 
Когда слайд-шоу приостановлено или запущено, вы можете изменить 
его внешний вид с помощью CSS. Идея состоит в том, чтобы использовать класс CSS.
В CSS класс может использоваться для описания вариации элемента. 
У вас может быть несколько элементов с одним и тем же классом, 
и в этом случае CSS будет применять к ним одни и те же свойства.

С помощью JavaScript можно присвоить или отменить присвоение класса элементу. 
Затем CSS применит или отменит применение свойств класса. 
В старых версиях JavaScript нужно было использовать свойство .className. 
Однако оно было заменено свойством classList, которое позволяет присваивать 
несколько классов и упрощает работу с ними.
 Чтобы добавить класс к элементу, используйте .classList.add(...) с именем класса; 
 чтобы удалить его, используйте .classList.remove():
 
	function toggle() {
		if(!running) {
			running = setInterval(next, delay);
			next();
			button.textContent = 'Stop';
			container.classList.add('running');
		}
		else {
			running = clearInterval(running);
			button.textContent = 'Start';
			container.classList.remove('running');
		}
	};
	
Соответствующая часть CSS:

	div#slides {
		outline: medium solid #666;
	}
	div#slides.running {
		outline-color: black;
	}

Вы увидите, что CSS меняет цвет границы, когда слайд-шоу приостановлено или запущено.

Реагирование на нажатие клавиши


Мы добавили кнопку для приостановки и возобновления слайд-шоу, 
но было бы немного удобнее, если бы мы могли делать это с помощью нажатия клавиши. 
Здесь мы можем использовать клавишу пробела.
 Если у вас есть поле ввода или элемент textarea, вы можете настроить 
 прослушиватель событий для реагирования на определенные нажатия клавиш 
 в этом элементе. В данном случае мы хотим, чтобы весь документ реагировал 
 на нажатие клавиши пробела, поэтому мы назначим прослушиватель событий самому документу:


	document.onkeypress = ...;

 Прослушиватель событий предназначен для события keypress, и здесь мы можем 
 использовать простую форму.  Как упоминалось ранее, прослушиватель событий — это всегда функция, 
 например функция toggle.  В этом случае нам понадобится другая функция, 
 которая сначала проверит, какая клавиша была нажата, а затем вызовет функцию toggle. 
 
 Пока что мы создали функцию с именем и назначили её в качестве прослушивателя событий, примерно так:
	
	button.onclick = toggle;
	function toggle() {
	};
	
 Такой способ определения функции полезен, если вы собираетесь 
 использовать её позже. Однако то же самое можно сделать, не определяя функцию отдельно:
 
	button.onclick = function() {
	
	};

Это называется функциональным выражением. Обратите внимание, что у этой функции 
нет имени, и в этом случае она называется анонимной функцией. Вы также можете присвоить ей имя:

	button.onclick = function toggle() {
	
	};
	
Однако имя будет доступно только внутри самой функции, поэтому вы 
нечасто будете встречать такой шаблон.
 Для нажатия клавиши мы воспользуемся той же идеей, чтобы создать 
 прослушиватель событий без создания отдельной функции:
 
	function doSlides(images, containerSelector, delay=3000) {
		...
		document.onkeypress = function(event) {
		};
		function toggle() {
		...
		}
		...
	};
Обратите внимание, что у функции также есть параметр. 
Всем обработчикам событий в качестве параметра передается специальный объект event, 
но во многих случаях вы можете не обращать на него внимания. Вы можете назвать его 
как угодно, но чаще всего его называют event, e или даже evt.
JavaScript позволяет игнорировать входящие значения параметров, как мы 
делали до сих пор. Однако на этот раз они нам понадобятся.

Объект события содержит всевозможную информацию о событии, 
например о том, где находилась мышь в момент события, 
была ли нажата клавиша Shift и какая клавиша вызвала событие. 
Нажатая клавиша указана в свойстве .key, и мы можем проверить это с помощью простого if():

	document.onkeypress = function(event) {
		if(event.key == ' ') {
			
		}
	};
	
Здесь нас интересует только клавиша пробела, поэтому мы просто используем строку с пробелом (' ').
 На этом этапе, если проверка пройдена, мы можем вызвать функцию toggle:
 
	document.onkeypress = function(event) {
		if(event.key==' ') {
		toggle();
		};
	};
	
Однако у браузера обычно есть собственное представление о том, как реагировать на 
определённые клавиши, и это может помешать нашим планам. 
Мы можем полностью изменить поведение, указав браузеру не продолжать 
реагировать с помощью функции event.preventDefault():

	document.onkeypress = function(event) {
		if(event.key==' ') {
			toggle();
			event.preventDefault();
		};
	};

В современном JavaScript есть альтернативный способ написания функционального выражения:

	document.onkeypress = event => {
		if(event.key==' ') {
			toggle();
			event.preventDefault();
		}
	};
По понятным причинам это называется стрелочным функциональным выражением. 
Стрелочные функции имеют простой синтаксис, что делает их удобными для написания 
обработчиков событий. В них также отсутствуют некоторые функции их традиционного аналога, 
что на самом деле может быть преимуществом в более сложном коде.
В данном случае использование стрелочного синтаксиса не даёт никаких реальных 
преимуществ, но вы всё чаще будете сталкиваться с тем, что обработчики 
событий пишутся именно так.

Добавление текста к подписи


Теперь мы можем добавить описательную подпись к каждому изображению. 
Подписи будут включены в массив названий изображений и отображены в 
специальном элементе абзаца, созданном с помощью JavaScript.

Объекты JavaScript

На данный момент массив images содержит только элементы с именами изображений. 
Если мы хотим добавить подписи, каждый элемент должен быть немного сложнее.
 Объект — это набор данных. В JavaScript есть множество предопределённых объектов, 
 но вы можете создать свой собственный объект, определив набор его свойств:
 
	var apple = {
		shape: 'round',
		colour: 'red'
	};

Это называется объектным литералом, так как вы определяете свойства в самом коде. 
В JavaScript объектный литерал заключён в фигурные скобки ({ ... }), 
которые выглядят как блок кода, но на самом деле таковыми не являются. 
На самом деле тот факт, что фигурные скобки используются для двух разных целей, 

	console.log(apple.colour);
	
Вы также можете изменить значение свойства:

	apple.colour = 'green';

Будьте внимательны при записи свойств объекта. По умолчанию JavaScript 
позволяет создавать новые свойства на лету, что не всегда является вашим намерением. Например:

	apple.Colour = 'green';
	
создало бы новое свойство под названием Colour, поскольку имена свойств, 
как и весь остальной JavaScript, чувствительны к регистру.
Конечно, вы можете записать литерал объекта в одну строку:

» var banana = { shape: 'long', colour: 'yellow' };

Если вы собираетесь создать много объектов с одинаковыми свойствами, 
но разными значениями, вы можете создать функцию-конструктор, которая сделает это за вас:

	function Fruit(форма, цвет) {
		this.форма = форма;
		this.цвет = цвет;
	};
	
	var вишня = новый объект Fruit('маленькая', 'чёрная');

На этом этапе мы не будем углубляться в создание функций-конструкторов.

Использование свойств объекта


Вместо того чтобы указывать только название изображения, теперь используется объект, 
содержащий название и подпись. Чтобы прочитать название, используйте images[...].src. 
Это будет внутри вычисляемого выражения ${images[...].src}:

	function next() {
		// Populate Image
		// img.src = `images/slides/${images[slideNumber++]}`;
		img.src = `images/slides/${images[slideNumber++].src}`;
		// Wrap Around
		if(slideNumber>=images.length) slideNumber = 0;
		// Prefetch
		// prefetch.src = `images/slides/${images[slideNumber]}`;
		prefetch.src = `images/slides/${images[slideNumber].src}`;
	};

По крайней мере, слайд-шоу снова работает.

Добавление подписи

Следующий шаг — создание элемента абзаца для подписи и его заполнение, когда придёт время.
Чтобы создать элемент абзаца, мы воспользуемся тем же методом, что и для кнопки:

	function doSlides(images, containerSelector, delay=3000) {
		// Элементы
		...
		// Добавить подпись
		let caption = document.createElement('p');
		container.insertAdjacentElement('beforeend', caption);
		// Переменные
		...
	};
	
 Здесь абзац добавляется в конец контейнера, после ранее добавленной кнопки. 
 CSS отвечает за расположение нового абзаца в контейнере и определение его внешнего 
 вида, например центрирование и выделение текста жирным шрифтом.
 Осталось только, чтобы функция next() заполнила подпись:
 
	function next() {
		// Заполняем изображение
		img.src = `images/slides/${images[slideNumber].src}`;
		caption.textContent = images[slideNumber++].caption;
		...
	};

Обратите внимание, что выражение slideNumber++ перенесено в оператор caption. 
Это связано с тем, что вы не хотите увеличивать slideNumber до тех пор, 
пока не закончите работу со старым значением. Если вам так удобнее, 
то следующий вариант может быть более понятным:

	function next() {
		// Заполняем изображение
		img.src = `images/slides/${images[slideNumber].src}`;
		caption.textContent = images[slideNumber].caption;
		slideNumber++;
		...
	};
	
В то же время вы можете задать свойство title для самого изображения, 
а также свойство alt, которое можно задать следующим образом: 

	function next() {
		// Заполнение изображения
		img.src = `images/slides/${images[slideNumber].src}`;
		caption.textContent = images[slideNumber].caption;
		img.title = images[slideNumber].caption;
		img.alt = images[slideNumber].caption;
		slideNumber++;
		...
	};

Свойство title изображения обычно не отображается, но при наведении 
курсора мыши на изображение появляется всплывающая подсказка.
