## [1.3.0] — 2026-09-23

### Добавлено
- 🌗 **Тёмная тема** для всех страниц проекта с переключением одной кнопкой.
- Сохранение выбранной темы в `localStorage`.
- Поддержка `prefers-color-scheme` — авто-выбор темы по настройкам ОС.
- 🌹 **Бегущая строка** (marquee) с фотографиями роз на странице «О проекте».
- Стилизация галереи: золотые паспарту в светлой теме, стеклянные рамки — в тёмной.
- **Золотая рамка** вокруг слайдера на главной в тёмной теме.
- Розовый акцент для заголовков слайдера в тёмной теме с тёмной подложкой.
- Единая дизайн-система через CSS-переменные (`--color-*`, `--radius`, `--shadow-*`).

### Изменено
- Сетка карточек на главной теперь строго **3 в ряд** на десктопе (было `auto-fill`).
- Кнопка «В избранное» на карточке стала компактнее — помещается целиком.
- Скрыто описание сорта на карточках в каталоге (`display: none`) — для чистоты.
- Метка с рейтингом на фото переработана в «стеклянную капсулу».
- Усилено затемнение под текстом на слайдере для лучшей читаемости.
- Обновлена типографика заголовков — `3rem` вместо `2rem` на десктопе.

### Исправлено
- Белый текст в шапке и кнопках в тёмной теме заменён на мягкий кремовый.
- Круг вокруг эмодзи-розы больше не светится белым в тёмной теме.
- Стрелки и точки слайдера перекрашены в розовый в тёмной теме.
- Убрано дублирование `filter` в `.rose-marquee__item img`.
- Исправлен конфликт `overflow: hidden` с золотой рамкой слайдера.
- Устранены «белые дыры» полей форм в тёмной теме.

## [1.2.0] — 2026-09-15

### Добавлено
- 📝 **Раздел отзывов и вопросов** с двумя вкладками.
- Форма добавления отзыва с оценкой звёздами.
- Голосование «Полезно / Не полезно» под каждым отзывом.
- Форма ответа на вопросы садоводов.
- Сводная карточка рейтинга с распределением по звёздам.
- Блок «Последние отзывы» на главной странице.

### Изменено
- Пагинация «Показать ещё» с индикатором оставшихся отзывов.
- Адаптив раздела отзывов: на мобильных — одноколоночная сетка.

## [1.1.0] — 2026-09-08

### Добавлено
- ❤️ **Страница «Избранное»** с сохранением в `localStorage`.
- Анимация добавления и удаления карточки из избранного.
- Пустое состояние с иллюстрацией, если избранное пусто.
- Счётчик избранных сортов в шапке страницы.

### Изменено
- Кнопка «В избранное» теперь имеет активное состояние (залита фирменным цветом).
- Карточки каталога стали отзывчивее к hover.

---

## [1.0.0] — 2026-09-01

### Добавлено
- 🎉 **Первый публичный релиз.**
- Главная страница с hero-слайдером и автопрокруткой.
- Каталог с фильтрацией по 9+ параметрам.
- Живой поиск по русскому и латинскому названию.
- Сортировка по популярности, рейтингу, названию.
- Активные фильтры-чипы с возможностью снятия.
- Страница сорта с таблицей из 12 характеристик.
- Динамическая подгрузка сорта по URL-параметру (`?id=`).
- Мини-галерея с переключением фото на странице сорта.
- Кнопка «Наверх» с плавным появлением.
- Адаптивная вёрстка от 320px до 1500px.
- Бургер-меню на мобильных.
- Премиум-анимации: 3D-свотчи цветов, hover-эффекты карточек.

### Технологии
- HTML5, CSS3 (Flexbox, Grid, CSS-переменные), JavaScript (ES6+).
- `localStorage` для сохранения избранного.
- GitHub Pages для хостинга.
