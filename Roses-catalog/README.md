Учебный пет-проект: многостраничный каталог роз с фильтрацией, поиском, сортировкой, избранным, отзывами и рейтингом. Написан на чистом **HTML**, **CSS** и **JavaScript** без фреймворков и сборщиков.

##  Демо

Проект опубликован на GitHub Pages:  
👉 **https://natalyasvetlakova.github.io/pet-projects/Roses-catalog/**

> Если демо пока не открывается — проверь, что в настройках репозитория (**Settings → Pages**) выбрана ветка `main` и папка `/Roses-catalog`. Тогда ссылка выше станет рабочей.

## ✨ Возможности

- **Главная страница** — слайдер с топ-сортами и карточки популярных роз.
- **Каталог** — фильтрация по категориям, поиск по названию (русскому и латинскому), сортировка, счётчик результатов.
- **Страница сорта** — динамическая карточка: описание, мини-галерея, отзывы, рейтинг.
- **Избранное** — сохранение сортов в `localStorage`, отдельная страница.
- **Отзывы** — добавление, удаление, расчёт среднего рейтинга на основе оценок.
- **Топ-отзывы на главной** — 6 лучших отзывов с оценкой ≥ 4 и длиной текста > 20 символов.
- **Защита лайков от накрутки** — пользователь не может лайкнуть один и тот же отзыв многократно.

## 🛠 Стек

- **HTML5** — семантическая разметка.
- **CSS3** — стили, адаптивная вёрстка.
- **JavaScript (ES6+)** — вся логика на клиенте, без библиотек.
- **localStorage** — хранение избранного и пользовательских отзывов.

## 🏗 Архитектура

Проект построен как **MPA (Multi-Page Application)** — несколько отдельных HTML-страниц, между которыми пользователь переходит по ссылкам. Общее состояние (избранное, отзывы) хранится в `localStorage` и доступно на всех страницах.

| Страница         | Назначение                                              |
|------------------|---------------------------------------------------------|
| `index.html`     | Главная: слайдер топ-сортов + карточки популярных роз    |
| `catalog.html`   | Каталог: фильтр по категориям, поиск, сортировка         |
| `rose.html`      | Страница сорта: описание, галерея, отзывы (динамическая) |
| `favorites.html` | Избранное: сорта, сохранённые пользователем              |
| `about.html`     | О нас (статичная страница)                               |

Каждая страница подключает только нужные ей JS-модули, а общие утилиты (`favorites.js`, `reviews.js`, `slider.js`, `data.js`) переиспользуются между страницами.

## Как это работает
Слайдер
Класс RoseSlider используется на двух страницах с разными настройками:

Главная (index.html): контейнер #hero-slider, автопрокрутка true, высота 500px.

Страница сорта (rose.html): контейнер #rose-gallery-slider, автопрокрутка false, высота 400px.

Один и тот же класс — разное поведение.

Каталог
Вся фильтрация и сортировка происходят на массиве roses в памяти, без запросов к серверу. Это быстро и подходит для GitHub Pages. Логика вынесена в catalog.js, стиль карточек — в createRoseCard, который используется и на главной, и в каталоге.

Отзывы и рейтинг
reviews.js собирает отзывы из двух источников:

seed-отзывы из data.js (поле reviews);

пользовательские отзывы из localStorage по ключу roses-catalog-reviews.

Средний рейтинг считается как среднее арифметическое оценок score. Если отзывов нет — используется резервный rating из data.js.

Сохранение отзыва:

Пользователь отправляет форму на rose.html.

addReview(rose.id, { author, score, text }) пишет данные в localStorage.

renderReviews() перерисовывает список.

На главной top-reviews.js читает тот же ключ, фильтрует по оценке и длине текста, сортирует и показывает лучшие.

Избранное
favorites.js хранит массив ID сортов в localStorage. На странице избранного favorites-page.js читает этот массив и отрисовывает карточки.
